# AI相棒スターターキット　使い方

## 1. はじめに

このキットは、自分で名前を付けた「AI相棒」と、文字か声で会話できるページです。
Node.js などのインストールはいりません。リンクを開くだけで使えます。
相棒の名前は、あなたが決めます。あなたの仕事や目標を書いた設定ファイルを読み込むと、相棒はそれを踏まえて答えてくれます。

公開URL：https://9mackeiri.github.io/ai-jvhiro-lp/kit/app/

## 2. 必要なもの

- ブラウザ：Mac の方は Safari、Windows の方は Chrome か Edge をお使いください（Mac の Chrome では、返事の読み上げが鳴らないことがあります）
- Anthropic Console のアカウントと API キー：Anthropic は Claude（クロード）という AI を作っている会社です。API キーは、あなたの相棒が Claude に問い合わせるための「合鍵」のような文字列です
- 料金：API は使った分だけの有料です。このキットの会話なら 1 往復で 1 円未満、毎日使っても月に数百円程度が目安です（キット自体は無料です）

## 3. API キーの取り方

1. https://console.anthropic.com/ を開き、アカウントを作ってログインします（メールアドレスか Google アカウントで作れます）
2. 左のメニューから「API Keys」を開きます
3. 「Create Key」を押し、名前（例：aibuddy）を付けて作成します
4. 表示されたキー（sk-ant- で始まる長い文字列）をコピーします。キーが表示されるのはこの一度だけなので、すぐにキットの設定画面へ貼り付けてください
5. 初めての方は、あわせて「Billing（お支払い）」から少額（5 ドル程度）のクレジットを入れておくと、すぐに会話できます

キーは他人に見せないでください。このキットの設定画面以外には貼らないでください。
もし他人に知られたと思ったら、Console の「API Keys」でそのキーを削除し、新しく作り直せば大丈夫です。

## 4. 使い方

1. 公開URL（上記）をブラウザで開きます
2. 設定画面が出ます。相棒の名前、あなたの呼ばれ方、API キーを入れます
3. 設定ファイルを読み込みます（任意）。「📄 ファイルを選ぶ」から「仕事.txt」「目標.txt」「今の状況.txt」をまとめて選べます。読み込んだ内容は、そのまま画面の欄で書き直せます
4. 「保存して会話をはじめる」を押します
5. 下の欄に文字を打って「送る」か、Enter キーで送ります
6. 声で話すときは、🎤 ボタンを押している間だけ聞き取ります。指を離すと送られます。初回はブラウザからマイクの許可を聞かれるので「許可」を選んでください
7. 相棒の返事は、文字で表示され、読み上げもされます（⚙ の設定で切れます）

設定はこのパソコンのこのブラウザにだけ保存されます。あとから ⚙ ボタンで開き直して直せます。

## 5. 設定ファイルの書き方

設定ファイルは 3 つあります。見本はここから保存できます：
https://9mackeiri.github.io/ai-jvhiro-lp/kit/settings/settings.zip （3 つまとめて）

- 仕事.txt：会社の規模、担当している業務、よく使う道具（Excel など）、パソコンの得意度。相棒が「あなたに合った言い方」をするための土台です
- 目標.txt：相棒と一緒にできるようになりたいこと（3 か月後・半年後）。相棒が「次の一歩」を示す目印になります
- 今の状況.txt：いま困っていること、今週やろうとしていること。状況が変わったら、このファイルだけ書き直せばよいです

各ファイルには、書き方の説明と記入例、あなたの記入欄が入っています。Mac の「テキストエディット」や Windows の「メモ帳」で開いて、記入欄を埋めて保存してください。
読み込む手順は、⚙ → 「📄 ファイルを選ぶ」→ 3 つを選ぶ → 「保存して会話をはじめる」です。ファイルを使わず、画面の欄に直接書いても構いません。

## 6. うまくいかないとき

- 返事が来ない：⚙ を開き、API キーが正しく貼れているか確認してください。キーは「sk-ant-」で始まります。Console のクレジット残高が 0 になっていないかも確認してください
- 読み上げが鳴らない：Mac の方は Safari で開いてください。⚙ の「🔊 テスト」で鳴るかどうかを確かめられます。鳴らないときはボタンの横に理由が出ます
- マイクが反応しない：ブラウザのアドレスバー左のアイコンから、マイクの許可を「許可」にしてください。Mac では「システム設定 → プライバシーとセキュリティ → マイク」でブラウザが許可されているかも確認してください
- 設定が消えた：ブラウザの履歴やサイトデータを消すと、設定も消えます。もう一度入れ直してください

## 7. 大事なこと

- 会話の内容と設定文は、返事を作るために Anthropic に送られます。会社や取引先、人の実名は「A社」「B部長」のように伏せ字で書くことをおすすめします
- API キーは、あなたのパソコンのこのブラウザにだけ保存されます。キットの作者にも送られません
- このキットは無料で配っています。API の料金だけは、各自の Anthropic アカウントでのお支払いになります
