使い方を読む

使用前に確認してください

  • ブラウザ：Mac の方は Safari、Windows の方は Chrome か Edge でお使いください。Mac の Chrome では、返事の読み上げが鳴らないことがあります。
  • Anthropic Console のアカウントと API キー：Anthropic は Claude（クロード）という AI を作っている会社です。API キーは、相棒が Claude に問い合わせるための「合鍵」のような文字列です。取り方は下の使い方にあります。
  • 料金：API は使った分だけの有料です。このキットの会話なら 1 往復で 1 円未満、毎日使っても月に数百円程度が目安です。キット自体は無料です。
  • 送られる情報：会話の内容と設定文は、返事を作るために Anthropic に送られます。会社や取引先、人の実名は「A社」「B部長」のように伏せ字で書くことをおすすめします。

使い方

1. API キーの取り方

  1. Anthropic Console を開いてログインする。
    console.anthropic.com を開き、「Googleで続行」か「メールで続ける」でアカウントを作ってログインします。
  2. 「APIキー」を開き、「＋ キーを作成」を押す。
    左メニューの「組織の設定」→「APIキー」を開き、右上の「＋ キーを作成」を押します。
  3. 「APIキーで続ける」を押す。
    「ID連携を使用すれば、APIキーは不要です」という案内が出たら、下の「APIキーで続ける」を押します。ID連携は企業向けの仕組みなので使いません。
  4. 名前・有効期限・スコープを決めて「キーを作成」。
    名前を入れます（例：aibuddy）。有効期限は初期値が 30 日なので、選べる中でいちばん長いものに変えます（期限が切れると「返事が来ない」状態になります）。スコープの欄を押して「デフォルトワークスペース」を選ぶと「キーを作成」が押せるようになります。
  5. 「キーをコピー」を押し、すぐ相棒の設定画面に貼る。
    「APIキーを保存」の画面で「キーをコピー」を押します。この画面を閉じると二度と表示されないので、すぐにキットの設定画面の「Claude APIキー」欄へ貼り付けてください。
  6. 「請求」で支払い方法を追加し、クレジットを入れる。
    左メニューの「請求」を開き、「支払い方法を追加」を済ませてから、「クレジットを購入」で少額（5 ドル程度）を入れます。自動チャージは切っておくと、使いすぎの心配がありません。

キーは他人に見せないでください。相棒の設定画面以外には貼らないでください。もし他人に知られたと思ったら、Console の「APIキー」一覧で右端の「⋮」からそのキーを削除し、新しく作り直せば大丈夫です。

2. 相棒の使い方

  1. 「相棒を開く」を押す。
    設定画面が出ます。
  2. 名前・呼ばれ方・API キーを入れる。
    相棒の名前は自分で決めます。候補を押しても、自由に入力しても構いません。
  3. 設定ファイルを読み込む（任意）。
    「📄 ファイルを選ぶ」から「仕事.txt」「目標.txt」「今の状況.txt」をまとめて選べます。読み込んだ内容は、そのまま画面の欄で書き直せます。
  4. 「保存して会話をはじめる」を押す。
    設定はこのパソコンのこのブラウザにだけ保存されます。あとから ⚙ で開き直せます。
  5. 話しかける。
    下の欄に文字を打って「送る」か Enter で送ります。声で話すときは 🎤 を押している間だけ聞き取り、指を離すと送られます。初回はブラウザからマイクの許可を聞かれるので「許可」を選んでください。返事は文字で表示され、読み上げもされます（⚙ の設定で切れます）。

3. 設定ファイルの書き方

設定ファイルは 3 つあります。見本は上の「見本を保存」から取れます。

  • 仕事.txt：会社の規模、担当している業務、よく使う道具（Excel など）、パソコンの得意度。相棒が「あなたに合った言い方」をするための土台です。
  • 目標.txt：相棒と一緒にできるようになりたいこと（3 か月後・半年後）。相棒が「次の一歩」を示す目印になります。
  • 今の状況.txt：いま困っていること、今週やろうとしていること。状況が変わったら、このファイルだけ書き直せばよいです。

各ファイルには、書き方の説明と記入例、あなたの記入欄が入っています。Mac の「テキストエディット」や Windows の「メモ帳」で開いて、記入欄を埋めて保存してください。読み込む手順は、⚙ → 「📄 ファイルを選ぶ」→ 3 つを選ぶ → 「保存して会話をはじめる」です。ファイルを使わず、画面の欄に直接書いても構いません。

4. うまくいかないとき

返事が来ない
⚙ を開き、API キーが正しく貼れているか確認してください。キーは「sk-ant-」で始まります。Console のクレジット残高が 0 になっていないか、キーの有効期限が切れていないか（APIキー一覧の「有効期限」列）も確認してください。
読み上げが鳴らない
Mac の方は Safari で開いてください。⚙ の「🔊 テスト」で鳴るかどうかを確かめられます。鳴らないときはボタンの横に理由が出ます。
マイクが反応しない
ブラウザのアドレスバー左のアイコンから、マイクの許可を「許可」にしてください。Mac では「システム設定 → プライバシーとセキュリティ → マイク」でブラウザが許可されているかも確認してください。
設定が消えた
ブラウザの履歴やサイトデータを消すと、設定も消えます。もう一度入れ直してください。

5. 大事なこと

  • 会話の内容と設定文は、返事を作るために Anthropic に送られます。実名は「A社」「B部長」のように伏せ字で書くことをおすすめします。
  • API キーは、あなたのパソコンのこのブラウザにだけ保存されます。キットの作者にも送られません。
  • このキットは無料で配っています。API の料金だけは、各自の Anthropic アカウントでのお支払いになります。
