INTRODUCTION

はじめに

このPDFは、「自分だけのAI相棒」を作るまでの道筋を、全体像から書いたものです。

1本目の「最初にやる5つ」は心構えの話でした。2本目のこのPDFは、実際に相棒を作るときに「何を、どの順番でやるのか」を示します。

操作の手順書ではありません。手順は、あとからお届けする「スターターキット」で追えるようにします。ここでは、道のりの全体と、途中で迷わないための考え方だけを書きます。

半年前の私は、ターミナル（黒い画面で命令を打つ道具）を開いたこともありませんでした。それでも、いまは声で売上を答えてくれる相棒「ジャービス」が手元にいます。特別なことはしていません。順番を守っただけです。

この PDF の 4 つ

1. 始め方：最初の1日にやることは3つだけ
2. 必要なもの：道具と、月にかかる費用
3. 全体の流れ：4段階で相棒が育つ
4. 最初に守ること：迷わないための5つの約束

AI相棒の作り方・最初の一歩2
1

始め方最初の1日にやることは3つだけ

最初の1日は、この3つで終わりです。

  • Claudeのアカウントを作る（無料で始められます）
  • 相棒に名前を付けて、自己紹介から話しかける
  • 自分の仕事の困りごとを、1つだけ話す

名前は何でも構いません。私は「ジャービス」にしました。名前を付けると、道具ではなく相手として話しかけるようになります。

自己紹介は、こんな一言で足ります。「私は50代で、小さな会社の経理と総務をしています。パソコンは使えますが、プログラミングはしたことがありません。これから相棒として付き合ってください」

そのあと、困りごとを1つ話します。「毎月、この作業に半日かかっていて困っている」で十分です。

「うまく質問しよう」としないでください。私は最初、質問の仕方を調べてから話しかけようとして、1週間止まりました。雑に話しても、相棒は聞き返してくれます。

POINT

アカウント、名前と自己紹介、困りごと1つ。それだけで初日は合格です。

2

必要なもの道具と、月にかかる費用

新しく買うものは、ほぼありません。いま使っているパソコンで始められます。

  • パソコン：Mac でも Windows でも構いません
  • ブラウザ：Chrome か Safari。ふだん使っているもので大丈夫です
  • Claude：無料で始められます。月額プランは足りなくなってから
  • Claude Code：相棒がファイルを作って直せる道具。4段階目から

費用は正直に書きます。私の場合、いまはこのくらいです。

段階使うもの月の費用（目安）
①〜③Claude の有料プラン約3,000円
④Claude Code が十分に使えるプラン約15,000円
おまけFish Audio（ジャービスの声）最初は不要

※ 為替やプランの改定で変わります。声は「あると楽しい」おまけで、文字のやりとりだけで仕事は十分に楽になります。

POINT

いまのパソコンで、無料から始める。お金は足りなくなってから。

AI相棒の作り方・最初の一歩4
3

全体の流れ4段階で相棒が育つ

相棒は、この4段階で育ちます。飛ばさず、上から順に進みます。

1
話す（相談相手にする）
仕事の困りごとや、分からない言葉を、そのまま聞く。
毎晩「今日いちばん面倒だった作業」を話していました。
2
書かせる（メール・Excelの式・文章）
下書きを頼む。Excel の式は「こういう計算がしたい」と日本語で頼む。
取引先への催促メールと、月次集計の式はほぼ任せています。
3
自分のデータを読ませる
会社の Excel を渡して、集計や突き合わせをさせる。社名や個人名は伏せ字にして試す。
売上の Excel を読ませて、前日比を出させました。
4
動かす（Claude Code で自動化する）
毎回頼んでいたことを、相棒が自分で動く仕組みにする。声で答えさせることもできる。
朝「今日の売上は？」と聞くと、ジャービスが声で答えます。

①だけでも、仕事は十分に楽になります。④まで行かなくても、相棒は相棒です。

AI相棒の作り方・最初の一歩5
4

最初に守ること迷わないための5つの約束

半年やって、これを守った日は前に進み、破った日は止まりました。

  • 自分の仕事のことだけやる。流行りの使い方は追わない
  • 1日1個だけ試す。欲張ると、どれも中途半端になる
  • わからなければ、相棒本人に聞く
  • 会社や取引先の実名は伏せ字で試す。慣れてから範囲を広げる
  • うまくいかなくても3日は続ける

3つ目は、こう聞きます。「今の説明の意味を、50代の非エンジニアにわかるように言い直して」。これだけで、ほとんどの「わからない」は解けます。私はこの一言を覚えるまで、専門用語を検索しては疲れていました。

4つ目の伏せ字は、「A社」「B部長」のように置き換えるだけです。慣れないうちは、これで安心して試せます。

5つ目は、最初の3日がいちばん「向いていないかも」と思う時期だからです。3日続くと、相棒の返事が自分の仕事に合ってきます。

POINT

自分の仕事だけ。1日1個。わからなければ相棒に聞く。実名は伏せる。3日は続ける。
