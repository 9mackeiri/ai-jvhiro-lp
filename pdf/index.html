INTRODUCTION

はじめに

このPDFは、50代・非エンジニアの会社員が、AIを始めて半年で「声で売上を答えてくれる相棒」を作るまでに、遠回りしたことを5つにまとめたものです。

難しい話はありません。最初の1か月で「これを知っていれば」と思ったことだけです。

この PDF の 5 つ

1. 何から触ればいいのか（道具の選び方）
2. 最初の1週間でやること
3. 「自分の仕事」に落とすコツ
4. つまずいたときの聞き方
5. 続けるための小さな仕組み

1

何から触ればいいのか道具の選び方

最初はChatGPT、Claude、Geminiと名前だけ知っていて、どれを使えばいいか分かりませんでした。

結論は「どれか1つに決めて、有料プランに入る」です。無料版を3つ試すより、1つの有料版を1か月使い込む方が、はるかに早く慣れます。

私はClaudeにしました。理由は、文章のやりとりが自然で、後から「コードを書いてもらう」段階に進みやすかったからです。月3,000円ほどで、仕事の道具として考えれば安い買い物でした。

POINT

どれか1つに決めて、有料プランに入る。

2

最初の1週間でやること

いきなり「業務を自動化しよう」と考えないことです。

最初の1週間は、毎日1つ、仕事のメールの下書きや、資料の要約、分からない言葉の説明を頼むだけでいい。大事なのは「AIに話しかける」のを習慣にすることです。

私は「今日の作業でいちばん面倒だったこと」を毎晩AIに話していました。そのうち「それ、こうすればできますよ」と返ってくるようになり、自動化の入口が見えました。

POINT

毎日1つ、AIに話しかけるのを習慣にする。

3

「自分の仕事」に落とすコツ

一般的な使い方の記事を読んでも、自分の仕事にはつながりません。

コツは「自分が毎月やっている作業を、そのままAIに説明する」ことです。「毎月末に、この表とこの表を突き合わせて、合わないところを探している」のように、実際の手順を口で説明するだけで、AIは「その突き合わせを自動でやる方法」を提案してきます。

私の最初の道具（入金の照合ツール）は、こうして生まれました。

POINT

毎月やっている作業を、そのままAIに説明する。

4

つまずいたときの聞き方

エラーが出たり、動かなかったりしたとき、私は最初「分からない」で止まっていました。

今は、画面のスクリーンショットをそのままAIに貼って「この画面で何をすればいい？」と聞きます。文章で説明しようとしなくていい。画面を見せる、が一番早い。

もう1つは「何を言っているか分からない」と正直に言うこと。そう言えば、AIは言い直してくれます。

POINT

画面を見せる。分からなければ、分からないと言う。

5

続けるための小さな仕組み

やる気は続きません。続いたのは、「AIとの会話を止めない仕組み」を作ったからです。

私の場合は、作った道具を毎日使う場面に置いたこと（朝、売上を聞く）と、次にやりたいことをAIに覚えさせておいたこと。翌日、AIに「昨日の続きは？」と聞けば、そこから再開できる。

自分の記憶力に頼らない、が50代のコツです。

POINT

自分の記憶力に頼らない。AIに覚えさせる。
