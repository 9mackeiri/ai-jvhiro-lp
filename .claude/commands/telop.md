## /telop — 動画にテロップを入れて書き出す

引数: `$ARGUMENTS`

### 1. 入力の受け取り

- **引数が空**のとき → 次の 1 行だけを聞いて、返答を待つ（他のことは書かない）：
  > 動画のパスを貼ってください（Finder からドラッグした形でOK。入力フォルダ内ならファイル名だけでも可）
- 引数（または返答）を**そのまま 1 つの文字列として** `zsh video/make.sh` の第 1 引数に渡す。make.sh 側で前後の空白・シングル／ダブルクォート・`file://`・`~/` を取り除き、絶対パスならファイル名だけを出力名にする。自分で加工しない（`'` を外し忘れて別の文字を足すなどの事故を防ぐため）
  - 例: `/telop` → `'/Users/hiroki/Movies/IMG_9020.MOV'` → `zsh video/make.sh "'/Users/hiroki/Movies/IMG_9020.MOV'"`
  - 例: `/telop IMG_9020.MOV` → `zsh video/make.sh IMG_9020.MOV`（iCloud の `Cursor/インスタ投稿/動画/入力/` 内のファイル）
- 絶対パスが入力フォルダ以外でも動く。出力先は従来どおり iCloud の `動画/字幕/`・`動画/出力/`・`動画/カバー/`（ファイル名だけで決まる）
- 受け取った動画名（拡張子を除いた `IMG_XXXX`）を**このセッションで覚えておく**（`/caption` の既定値になる）

### 2. 実行（1 回目）

```bash
cd ~/dev/ai-jvhiro-lp && zsh video/make.sh <受け取った文字列>
```

- 初回は文字起こし → 要点テロップの下書き `字幕/<名前>.highlight.txt` を作って**止まる**（仕様。勝手に書き出さない）
- 止まったら、下書きの内容を表示し、木田に「文を短く直してください。直したら『OK』と言ってください」と伝えて待つ。木田が「そのまま」「直した」「OK」と言ったら 3 へ
- 木田が下書きの修正を Claude に頼んだ場合は、`highlight.txt` を直してから 3 へ（q は質問、n は数字、a は一言。相づち・お礼は出さない）

### 3. 実行（2 回目・書き出し）

```bash
cd ~/dev/ai-jvhiro-lp && zsh video/make.sh <同じ文字列> --skip-transcribe
```

（1 回目に `--crop` `--end` `--title` などを付けていたら同じものを付ける）

- 完成すると `動画/出力/<名前>_reel.mp4`、静止画 `動画/出力/確認用/<名前>/`、カバー `動画/カバー/<名前>_cover.png` ができる
- カバーの見出しは `字幕/<名前>.cover.txt` から読む。無ければ「見出し未設定」で作られるので、Day 番号と見出し 2 行を聞いて書き、`--skip-transcribe` でもう一度実行する（書式は `video/README.md` の「カバー画像」）

### 4. 報告（短く）

- 完成した動画・カバーのパス
- 確認用静止画のフォルダ（`_冒頭` `_中盤` `_終盤` と `_cover_4x5`）
- 「次は `/caption` でキャプションを作れます」と 1 行

### 注意

- 動画・音声・字幕・画像はコミットしない（`.gitignore` 済み。`出力/` は追跡外）
- iCloud 上で実体が未取得（dataless）の動画は make.sh が自動で取得を待つが、大きいと 10 分以上かかる。止まって見えたら「iCloud から取得中」と伝える
- `--end 秒` で末尾を切れる。撮り終わりの手ブレを切りたいと言われたら、終盤の静止画を見て秒数を提案する
