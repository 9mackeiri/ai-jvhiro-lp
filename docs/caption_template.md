# リール投稿のキャプションの型（/caption が使う）

数字は SRT／highlight.txt にあるものだけ使う（作らない）。製品名・取引先名は出さない（「乳酸菌サプリ」「病院」「薬局A」の言い方まで）。
コメントの合言葉 `<合言葉>` は毎回変わる。その回の SRT でジャービスが言う「コメントに『○○』とだけお書きください」の ○○ をそのまま入れる（SRT に無ければ木田に聞く）。無料PDF・DM の導線は固定。
「必ず」「誰でも」などの断定はしない。同じ語尾を 3 回以上続けない。

## Instagram 用

```
Day N｜<見出し。カバーの 2 行を 1 行にした言い回し>

50代・非エンジニア・小さな会社の経理総務。
プログラミングは書けません。

半年前にAIを始めて、
声で聞くと本物の売上データから答えてくれる相棒『ジャービス』ができました。

<その回の質問→数字→見どころ。3〜6 行。1 行 30 字以内>

会社のExcelを読んで、声で返す。
画面も声も、全部自分で作りました（製品名と取引先名は伏せています）。

『今からじゃ遅い』と思っている同年代へ。
できたことを、ありのまま毎日出していきます。

作り方が知りたい方は、フォローして
コメントに『<合言葉>』と書いてください。
AI相棒の作り方をまとめた無料PDFを、DMでお届けします。

#50代からのAI #AI相棒 #非エンジニア #AI活用 #AI初心者
```

## TikTok 用

```
Day N｜<見出し。Instagram と同じ>

50代・非エンジニアが自分で作ったAI相棒『ジャービス』。
声で聞くと、会社の本物の売上データから答えてくれます。

<その回の質問→数字→見どころ。Instagram と同じ 3〜6 行>

会社のExcelを読んで、声で返す。
画面も声も、全部自分で作りました（製品名と取引先名は伏せています）。

『今からじゃ遅い』と思っている同年代へ。
できたことを、ありのまま毎日出していきます。

フォロー＋コメント『<合言葉>』で、AI相棒の作り方PDFをDMで無料プレゼント

#50代からのAI #AI相棒 #非エンジニア #AI活用 #AI初心者 #Claude #ジャービス
```

## 見どころの書き方（4 のブロック）

- 1 行目：その回の質問（「今日の売上を聞いたら」）
- 2〜3 行目：数字（「84,259円。病院から乳酸菌サプリ3個と腸活サプリ27個」「昨日より 59.4% 下回った」）
- 残り：AI の一言や意外な展開（「AIが『比べないで』と言った」）
- 動画の最後にお知らせの掛け合いがある回は、最後に次の趣旨を入れる：
  「最後の『ありがとう』のあと、ジャービスが言い出した『お知らせ』。この掛け合いも自分で設定しました。」

## 保存先

iCloud `Cursor/インスタ投稿/動画/字幕/<名前>.caption.txt`（Instagram 用 → 区切り線 → TikTok 用）。既にあれば `.caption.txt.bak-日時` に控えてから上書き。
